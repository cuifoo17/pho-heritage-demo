# Pho Heritage Website

Demo site. Next.js 16 + Tailwind v4, static export.

- `npm run dev` then open http://localhost:3000
- `npm run build` writes the static site to `out/`
- Scenes live in `public/scenes/` (animated SVG, one per page)
- Menu, hours, and reviews live in `src/data/` and are meant to move to a Google Sheet later
- "Order now" is a placeholder; point it at the Toast online-ordering URL
